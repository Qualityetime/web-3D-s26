Project Goal

I wanted to create a prehistoric hunting simulation where animals respond to the player and their changing condition. The project explores how perception, threat assessment, and localized injuries can produce believable behavior during a hunt.

For the portfolio edition, my goal was to turn the multiplayer prototype into a single-player experience visitors can play immediately in a desktop browser, while making the simulation easier to inspect through live telemetry.

Tools Used

  • JavaScript and Three.js for the 3D world, first-person controls, and gameplay simulation.
  • React, HTML, and CSS for menus, the HUD, settings, results, and telemetry.
  • Vite, GitHub Actions, and GitHub Pages for production builds and automated publishing.
  • Node.js and Socket.IO for the original four-player multiplayer prototype.

What I Built

I developed a first-person hunting experience with a complete hunt, harvest, and cook loop. The portfolio edition brings that simulation into the browser through a local adapter and adds a React interface around the Three.js game.

  • Interactive hunting systems. Spear thrusts and throws, bracing against charges, localized wounds, bleeding, harvesting, and campfire cooking.
  • Reactive boar AI. Animals perceive the hunter, assess pressure, and shift between warning, attacking, fleeing, and recovering as the encounter changes.
  • Live simulation telemetry. A tactical map and behavior, pressure, blood, and wound readings make the AI’s changing state visible during play.
  • A complete application interface. A briefing, health and stamina HUD, pause and settings menus, hunt results, and restart controls support the playable experience.
  • A browser-ready portfolio edition. The original simulation runs locally, with 200 automated tests and a GitHub Actions workflow that tests, builds, and publishes the demo.

The playable demo is single-player. Multiplayer belongs to the original Node.js and Socket.IO prototype.
