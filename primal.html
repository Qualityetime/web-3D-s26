Project Primal

Track wild boars through a prehistoric ravine, hunt with a spear, and return to camp to cook your first meal.

Play Demo ↗ View Source ↗

Single-player demo. Opens in a new tab. Desktop keyboard and mouse required.

Inside the simulation

The boars react to line of sight, nearby threats, and injuries. Press T during a hunt to see their behavior, pressure, and wound status as they change.

The portfolio edition runs the original simulation in the browser with a React interface and a Three.js world. The original four-player prototype used a Node.js and Socket.IO server to synchronize the hunt.
