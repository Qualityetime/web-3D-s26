Cabinet of Curiosities

Cabinet of Curiosities is an interactive 3D web project built with Three.js. The project explores how a website can feel more like a small digital environment instead of a flat page. I designed the piece around the idea of a strange personal collection space, where objects, images, and visual details are arranged like artifacts inside a virtual room. The goal was to create something that felt mysterious, atmospheric, and explorable while still functioning as a browser-based interactive experience.

Project Goal

The goal of this project was to experiment with 3D space on the web and create an interactive scene that users could move through or explore visually. Instead of making a normal webpage, I wanted the experience to feel like entering a digital cabinet filled with objects and references. I focused on mood, spatial layout, camera control, object placement, and how the viewer’s movement changes the way they read the space.

Tools Used

  • Three.js
  • HTML, CSS, and JavaScript
  • 3D scene setup and object placement
  • Camera controls and interaction design
  • Texture and image mapping

What I Built

For this project, I built a browser-based 3D scene using Three.js. I worked on setting up the environment, placing objects in the scene, controlling how the camera moves, and creating a space that felt organized but still strange and personal. I also experimented with using images and surfaces as visual elements inside the scene, so the project could act like both a digital room and a visual archive.
